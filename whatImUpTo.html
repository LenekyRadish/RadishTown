Dice Rolling Graph

I coded this in python using Pygal so that you enter the number of sides on each die and the times rolled, and it gives you the frequencies!

Random Walk Graph

I coded this in python using MatPlotLib so, for a given amount of points, the x and y distance travelled in each "step" is random and can either be positive or negative, and it looks really cool!

Temperature Graph

Another python project! For this one, you input any month or select the entire year, and it gives you the weather data for that time period in 2025! It's color-coded based off of different temperature benchmarks, and I think it looks really nice :)
